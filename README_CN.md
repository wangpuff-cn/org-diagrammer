# org-diagrammer

**交互式股权架构图 / 组织架构图生成器** · V1.0 · [English README](README.md)

一份 Excel 进去，一张可交互的架构图（独立 HTML）出来。无需联网、无外部依赖，生成的 HTML 可直接转发分享，浏览器打开即用。

---

## 功能一览

| 能力 | 说明 |
|------|------|
| 双模式 | 股权架构图（equity）/ 组织架构图（org），按 Excel 表头自动识别 |
| 折叠 / 展开 | 节点底边徽章点击折叠分支；折叠后自动重排恢复正常间距；支持"全部展开 / 全部折叠 / 折叠至 N 层" |
| 搜索定位 | 实时下拉（最多 10 条）；选中后**精确锁定该节点 + 向上穿透至顶层**高亮，链路连线加粗；自动放大定位（≤500%）；打字过程为子串预览 |
| 点击穿透 | 点击节点 = 向上溯源 + 向下穿透双向高亮，链路加粗；点空白处恢复 |
| 黑白 ⇄ 彩色 | 一键切换；Excel 填了节点颜色时默认彩色 |
| 缩放 | 下拉菜单（适应窗口 + 50%~1000%）+ ＋/− 步进按钮；已禁用手势缩放防误触 |
| 悬停详情 | 股权节点：主体业务及职能、股东与比例；组织节点：职能、负责人、正编/外包人数、上级 |
| 导出 | SVG / PNG / PDF |
| 分享 | 单个独立 HTML 文件，标签页标题 = 图名 |

## 视觉规范

- 圆角长方形节点，同一层级等宽（以该层最长名称为准、紧凑贴合文字）
- 名称 14pt（超长自动缩字不换行）、地区行 12pt（国家/省/市/区）
- 正交折线：实线 = 直接持股/直接管理，虚线 = 协议控制/虚线汇报；干线在上下层间居中
- 默认黑白线框（打印友好）；上市主体加粗边框；有填充色的节点自动带色
- 同一母公司/上级同层子节点过多自动换行（股权 >10、组织 >15），有下层分支的排靠下行

## 快速开始

### 环境要求

Python 3.8+，仅依赖 `openpyxl`（Kimi Work 托管 Python 自带）。

### 一条命令出图

```bash
python3 scripts/build_equity_json.py 你的股权模版.xlsx \
    --title "XX公司股权架构图" \
    --html 输出/XX公司股权架构图.html
```

- `--mode auto`（默认）自动识别 equity/org；也可显式 `--mode equity|org`
- `--json out.json`：只输出布局 JSON（接入自研前端时用）
- 不带 `--json/--html`：JSON 输出到 stdout

### Excel 模版

`assets/` 目录自带两份填写模版，各含示例数据：

- **`股权架构图填写模版.xlsx`**（13 列）：节点颜色 / 层级编号 / 公司名称 / 国家 / 省 / 市 / 区 / 股权关系 / 境内·境外 / 股东·母公司 / 持股比例 / 主体业务及职能 / 特殊要求
  - 节点颜色 = 单元格**填充色**（填色即上色）
  - 多股东用 `/` 分隔：`张三/李四` + `68%/32%`
  - "主体业务及职能"含"上市"→ 自动识别为上市主体
- **`组织架构图填写模版.xlsx`**（9 列）：节点颜色 / 层级编号 / 部门·组织名称 / 负责人 / 组织职能 / 人数 / 管理关系 / 上级部门·组织 / 特殊要求
  - 上级列支持公式（如 `=C$2`）
  - 人数支持公式或 "正编 156 外包 69" 文本

列顺序可调整（按列名匹配）；表头以外的空行/说明 sheet 不影响解析。

## 工作原理（简述）

1. **解析**：openpyxl 双开（样式 + 公式缓存值），按列名匹配表头，还原主题色+tint 填充色
2. **布局**：tidy-tree（父居中于子；子树占位 = max(自身宽, 子代跨度)，防止宽父挤压邻居）、同层等宽、超限兄弟组换行
3. **路由**：正交折线，fan-out 按子节点分段水平线（高亮不溢出），fan-in 共用汇线，干线居中于上下层
4. **注入**：JSON 替换模板 `/*__EQUITY_DATA__*/` 占位符，标题替换 `/*__CHART_TITLE__*/`，产出单文件 HTML

## 在 Kimi Work 中作为 Widget 展示（可选）

默认交付独立 HTML 即可。如需出现在对话/看板：创建 Blueprint Widget → 将模板写入其 `index.html` → 注入数据与标题 → `Widget.show`。详见 SKILL.md。

## V1.0 迭代记录

- 双模式解析（股权/组织），组织模式悬停展示职能信息
- 同层等宽 + 宽度贴合文字（去量化取档）
- tidy-tree 子树宽度修正（父宽 > 子树跨度时不再挤压邻居）
- 搜索：精确锁定 + 仅向上穿透高亮 + 链路连线加粗 + 放大定位
- 连线高亮归属修正（共用段多端归属 + `\x01` 分隔，链路全程点亮不溢出）
- 折叠/展开分支 + 层级折叠下拉 + 折叠后自动重排
- 缩放下拉（50%~1000% + 适应窗口）、＋/− 等宽按钮、禁手势缩放
- 导出 SVG / PNG / PDF；独立 HTML 标签页标题 = 图名

## 已知边界

- 悬空引用（股东/上级不在节点表内）的边会被丢弃
- 名称极长时字号缩至 6pt 保底（仍单行不换行）
- 修改模板 `index.html` 后必须保留两个占位符注释，否则注入失败
